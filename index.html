/01Flagship · Consumer app · Multimodal AI
Buntikki Technologies · 2026

PocketPins

Smart Collections for an iOS & Android app that turns saved Instagram reels into a personal, searchable library. pocketpins.app ↗

The problem

People save hundreds of reels — cafés, trips, recipes — and never find them again. One-AI-call-per-reel folders came out broad, duplicated, and mixed up cities.

What I'm building

A save-time organiser: places become Trips, Lists and Vibes per city, place-less reels like recipes and workouts still get a home, and nothing reshuffles once filed.

From share to collection
Share a reelRead it in 3 passesVerify on Google MapsSave once, share across usersFile into collectionsReply + notify
3-passmultimodal reading — caption, then cover image, then video + audio
1×AI read per reel, cached and reused for every user who saves it
886automated checks, plus end-to-end runs on real reels
Engineering decisions
  • →Decide once, never reshuffle. Each place is filed at save time; unsure ones wait in “Recently saved” until a second match forms a collection. Names are locked.
  • →Patterns, not one-offs. A collection is created only when two places share a strong reason in the same city — no single-reel folders.
  • →The user always wins. Unsaves, deletes and removals are respected for good; a deleted collection is never re-created.
  • →Idempotent by design. Deterministic IDs inside transactions mean simultaneous saves can't create duplicates; rate limits keep users from being flooded.
  • →Ship dark first. An off / shadow / live switch lets the engine run on real saves before users ever see it.
  • →An outage isn't an answer. AI failures are retried instead of being misread as “no places” — so recipe and workout reels are saved, not lost.

/02EdTech · RAG + agent
Arna Intelligence · freelance

Globiculum

AI curriculum-transition platform for students moving between education systems.

The problem

A student moving from US Common Core to an Indian board hits a curriculum cliff — and nobody can say exactly where the gaps are, or what to study first.

The result

A personalised gap analysis and phase-wise bridge plan in under 10 minutes, built to extend to ICSE, state boards and US state curricula.

How it works — tap a stageStage 01 / 06
01Ingest the standards

Python pipelines break NCERT and US Common Core into curriculum nodes — subject, grade band and learning objective — ready to embed.

Engineering decisions
  • →Retrieve before reasoning. pgvector over Gemini embeddings matches curricula by meaning, so the agent reasons over evidence instead of memory.
  • →Schema-first outputs. Structured JSON is parsed and validated before anything reaches the dashboard.
  • →Guardrails at the edge. JWT auth, rate limits and request validation live inside the Edge Functions, not the client.

/03FinTech · Multi-agent

Autonomous FinOps Multi-Agent

Problem

Fraud review needs a reason for every decision — and financial data shouldn't leave the building.

Built

Five agents — Investigation, Policy-RAG, Decision, Action, Explanation — producing an auditable JSON risk report.

0external API keys — runs fully local on Llama 3 via Ollama
Engineering decisions
  • →Local-first. Llama 3 via Ollama keeps transaction data on the machine.
  • →Deterministic scoring. A 0–10 risk score with reason codes keeps every decision auditable.
  • →Bounded actions. Four outcomes only — approve, verify, hold, manual review.

Video-to-SOP

Problem

Built
