Chapter 02 — The craft

A demo is a prompt. A product is everything around it.

01

Ground it

Retrieval over real sources, with source URLs injected into the answer — so every claim can be traced.

in → Globiculum, FinOps
02

Constrain it

Structured JSON outputs and tool calling, parsed and validated — the backend never guesses what the model meant.

in → every system here
03

Verify it

Hallucination detection and post-processing checks run before anything reaches a user.

in → Globiculum, Telic agents
04

Observe it

Agent traces, tool-call logs, retries and failure handling — production stays boring, in the good way.

in → FinOps, Video-to-SOP
